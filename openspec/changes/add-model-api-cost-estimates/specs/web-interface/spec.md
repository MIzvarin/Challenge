# Spec Delta

## ADDED Requirements

### Requirement: Стоимость в карточках всех разделов
Каждая карточка результата во всех разделах SHALL показывать «Примерная стоимость: ≈ … USD» рядом с токенами либо «Стоимость недоступна» при null или старом ответе без cost. Интерфейс SHALL объяснять, что это оценка по опубликованным API-тарифам, а не фактическое списание Go. Текст ответа, длительность, токены, ошибки и раскрывающиеся этапы SHALL сохраняться.

#### Scenario: Все варианты генерации
- **WHEN** пользователь открывает ответы DeepSeek с effort low/max, любой температуры, Kimi, Grok или GPT
- **THEN** каждая карточка содержит собственную оценку из ответа сервера без клиентского пересчёта по текущему тарифу
- **AND** источник и версия тарифа доступны через раскрываемые сведения без обязательного наведения мыши

#### Scenario: Маленькая положительная сумма
- **WHEN** положительная стоимость меньше 0.000001 USD
- **THEN** интерфейс показывает «Примерная стоимость: < 0,000001 USD», не округляя её до нуля
- **AND** для остальных сумм используются русская локаль и до шести дробных знаков, а подтверждённый ноль показывается как 0 USD

#### Scenario: Старая или неизвестная цена
- **WHEN** карточка содержит null cost или восстановлена из старой истории без cost
- **THEN** видны «Стоимость недоступна» и прежний ответ без ошибки или фиктивной суммы

### Requirement: Денежный итог сравнения и цены этапов
В режиме compare интерфейс SHALL показывать оценку каждой карточки и общий итог над сеткой только при известной стоимости всех подходов; иначе SHALL показывать «Общая стоимость недоступна». У завершённых промежуточных этапов SHALL показываться собственная цена либо её недоступность без повторного прибавления к карточке.

#### Scenario: Четыре успешных подхода
- **WHEN** четыре результата имеют известные цены
- **THEN** над сеткой показана общая приблизительная стоимость, а внутри — цены соответствующих подходов и этапов

#### Scenario: Один неоценённый подход
- **WHEN** один подход завершился ошибкой или имеет неизвестную цену
- **THEN** общий итог недоступен, остальные известные цены и сообщения ошибок остаются видимыми

### Requirement: Проверка денежных метаданных
Браузер SHALL проверять форму cost, валюту, десятичный amount, версию и HTTPS-источник, а также согласованность известных итогов с результатами. Некорректное присутствующее поле SHALL не приниматься как допустимая цена. Старый формат без cost SHALL поддерживаться только для чтения истории; новый сетевой ответ SHALL требовать cost на всех предусмотренных уровнях.

#### Scenario: Некорректные суммы
- **WHEN** новый сетевой ответ содержит отрицательную сумму, NaN, число вместо строки, другую валюту, лишние поля или противоречащий результатам итог
- **THEN** браузер отклоняет его как некорректный ответ API, сохраняя прежнюю переписку и черновик

#### Scenario: Отсутствующее новое поле в сети
- **WHEN** новый сетевой ответ не содержит cost в результате или этапе
- **THEN** браузер показывает ошибку несовместимого ответа, не выдавая его за новый корректный формат
