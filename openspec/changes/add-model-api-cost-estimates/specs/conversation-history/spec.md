# Spec Delta

## ADDED Requirements

### Requirement: Неизменная оценка в истории
Система SHALL сохранять cost ответа, результатов и этапов вместе с версией и источником тарифа в существующих локальных историях всех разделов. Перезагрузка, переключение вкладок и обновление тарифов SHALL не пересчитывать сохранённую цену. Денежные метаданные SHALL не включаться в передаваемый модели текст контекста.

#### Scenario: Тариф обновился
- **WHEN** ответ с ценой по версии A сохранён, сервер перешёл на версию B и пользователь перезагрузил страницу
- **THEN** прежний ответ показывает сохранённую цену и версию A, а новый может использовать B
- **AND** для чтения истории запрос к провайдеру не выполняется

#### Scenario: Следующий вопрос
- **WHEN** пользователь продолжает диалог с оценённым многоэтапным ответом
- **THEN** контекст содержит прежние тексты вопроса, этапов и ответа без цен, URL источников или версии тарифов

### Requirement: Совместимость истории без денежных полей
Обновление SHALL читать корректные прежние ответы без cost во всех разделах, трактуя цену как недоступную, без удаления диалогов, смены поколения или повторного сброса ревизии. Новые и старые ответы SHALL сосуществовать в одной истории. Повреждённое присутствующее cost SHALL проверяться, а не игнорироваться как старый формат.

#### Scenario: Смешанная история
- **WHEN** в существующей истории DeepSeek или модели есть старый ответ без cost и новый ответ с cost
- **THEN** оба восстанавливаются в своём диалоге, старый не получает выдуманную цену
- **AND** UUID поколения и действующий маркер ревизии не меняются из-за добавления оценки

#### Scenario: Межвкладочная очистка
- **WHEN** одна вкладка сохраняет ответ с cost, а другая очищает историю до применения позднего ответа
- **THEN** прежние блокировки и проверка поколения предотвращают восстановление удалённых сообщений вместе с ценой

#### Scenario: Повреждённая цена
- **WHEN** сохранённый ответ содержит cost с отрицательным amount или неверной структурой
- **THEN** действует предупреждение о некорректной истории без немедленной перезаписи исходного хранилища
