# Spec Delta

## MODIFIED Requirements

### Requirement: Серверный вызов OpenCode Go
Для `/api/ask` сервер SHALL вызывать `https://opencode.ai/inference/go/openai/v1/chat/completions` с моделью `deepseek-v4.1-flash`, серверным ключом в `Authorization: Bearer`, идентификатором клиента в `User-Agent` и идентификатором сессии в `x-opencode-session`. Раздел «Модели» SHALL использовать отдельную маршрутизацию Go по выбранной модели. Браузер SHALL обращаться только к локальному API приложения без ключа провайдера.

#### Scenario: Успешная отправка вопроса
- **WHEN** сервер обрабатывает допустимый запрос с настроенным ключом
- **THEN** обращение к Go содержит выбранную разрешённую модель, сообщения и серверные заголовки
- **AND** API-ключ не включается в ответ приложения браузеру

## ADDED Requirements

### Requirement: Протокол выбранной модели
Сервер SHALL вызывать только выбранную модель: kimi-k2.7-code через Go OpenAI Chat Completions, grok-4.7 и gpt-6-luna — через Go OpenAI Responses. Обращение SHALL использовать существующий серверный ключ в Authorization Bearer, User-Agent и x-opencode-session, русскоязычную инструкцию, собственную историю модели и новый вопрос, без temperature, thinking, reasoning_effort и бюджетов генерации приложения.

#### Scenario: Маршрутизация выбранной модели
- **WHEN** отправлен вопрос из вкладки Kimi
- **THEN** выполняется один вызов выбранной модели через `/inference/go/openai/v1/chat/completions` с stream false

#### Scenario: Маршрутизация Responses
- **WHEN** отправлен вопрос из вкладки Grok или GPT‑6 Luna
- **THEN** выполняется один вызов `/inference/go/openai/v1/responses` с точным model grok-4.7 или gpt-6-luna, stream false, русскоязычной инструкцией и всей историей выбранного диалога
- **AND** другие модели и Google endpoint не вызываются

### Requirement: Проверка завершённого ответа Responses
Responses-адаптер SHALL принимать только ответ status completed без error с завершёнными сообщениями assistant, непустым итоговым output_text и целым неотрицательным usage.total_tokens. Reasoning-элементы SHALL не подменять ответ и не сохраняться. Refusal, incomplete, failed, незавершённые сообщения, пустой текст и недостоверная статистика SHALL считаться отказом без выдачи частичного текста.

#### Scenario: Итог и внутренние рассуждения
- **WHEN** Responses возвращает completed с reasoning-элементом и завершёнными текстовыми сообщениями assistant, а usage.total_tokens равен 0
- **THEN** итог собирается только из output_text в исходном порядке, обрезается по краям и содержит фактический расход 0

#### Scenario: Отсутствие полного ответа
- **WHEN** Responses возвращает incomplete, failed, refusal, пустой output, ошибку внутри HTTP 200 либо некорректный расход
- **THEN** запрос получает безопасную HTTP-ошибку без частичного ответа, внутренних рассуждений и выдуманных токенов

### Requirement: Изоляция сессий моделей
Сессия диалога модели SHALL устойчиво определяться conversation_id и model в отдельном пространстве моделей, различаться между моделями и существующими разделами и меняться после очистки. Формула прежних сессий SHALL оставаться неизменной; согласованный однократный сброс SHALL менять conversation_id всех разделов и их сессии.

#### Scenario: Продолжение диалога после перезагрузки
- **WHEN** отправлен следующий вопрос выбранной модели с тем же conversation_id после перезагрузки
- **THEN** она получает прежний собственный session ID, не совпадающий с другими моделями или DeepSeek-разделами

### Requirement: Отказы новых моделей
Новые адаптеры SHALL сохранять тайм-ауты подключения 10 секунд и бездействия 180 секунд, безопасное преобразование HTTP-ошибок и запрет автоматических повторов, смены модели или endpoint при отказе. Сообщения SHALL не приписывать отказ Kimi, Grok или GPT провайдеру DeepSeek и не раскрывать ключ, диагностику или метаданные.

#### Scenario: Недоступен Grok
- **WHEN** Go возвращает для Grok 403 или сетевой тайм-аут
- **THEN** одиночный запрос получает соответственно HTTP 503 либо 504 с безопасным detail без повторного вызова, запуска другой модели и раскрытия сырого ответа
