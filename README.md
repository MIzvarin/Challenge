# Challenge — вопрос → ответ

Минималистичный React-интерфейс и Python-бэкенд, который отправляет вопросы в
OpenRouter API. Без регистрации в приложении, базы данных и истории диалогов:
каждый вопрос независим. Для API нужен аккаунт OpenRouter.

## Стек

- Python **3.15.2**, FastAPI, HTTPX.
- React **19.3.0**, TypeScript, Vite; Node.js **22.12+**, npm **11+**.
- Модель по умолчанию: `nvidia/nemotron-3.5-lightning:free` через OpenRouter.

## API-ключ

1. Создайте ключ на <https://openrouter.ai/settings/keys>.
2. Впишите его в **корневой `.env`** (пустой файл уже подготовлен локально):

   ```dotenv
   OPENROUTER_API_KEY=ваш_ключ
   OPENROUTER_MODEL=nvidia/nemotron-3.5-lightning:free
   ```

   После клонирования создайте `.env` из шаблона: `cp .env.example .env`.
3. После изменения `.env` перезапустите бэкенд.

`.env` и `.env.*` исключены из Git; `.env.example` содержит только пустой шаблон.
Не помещайте ключ в React, `VITE_*`, URL, логи или README. Переменные окружения
процесса имеют приоритет над `.env`. Сервер читает файл относительно расположения
проекта, независимо от текущей директории.

## Локальный запуск

Из корня проекта, с установленным Python 3.15.2:

```sh
python3.15 -m venv .venv
source .venv/bin/activate
python -m pip install -e './backend[dev]'
python -m uvicorn app.main:create_app --factory --reload --host 127.0.0.1 --port 8000
```

В другом терминале, из `frontend/`:

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Vite проксирует `/api` на бэкенд — браузер не
обращается к OpenRouter напрямую. CORS с разрешением всех доменов не нужен.

## Сборка

Из `frontend/`:

```sh
npm run build
```

После сборки перезапустите бэкенд **без `--reload`**. Он отдаёт интерфейс из
`frontend/dist` по <http://127.0.0.1:8000>, а не из корня репозитория. `.env`
недоступен через HTTP. `npm run preview` предназначен только для просмотра статики:
для запросов к ИИ используйте Vite dev-сервер или собранный интерфейс на бэкенде.

## Проверки

Инструкции размещения на сервере: [docs/deploy.md](docs/deploy.md).

В активированном Python-окружении, из `backend/`:

```sh
python -m pytest
```

Из `frontend/`:

```sh
npm run lint
npm test
npm run build
```

Тесты подменяют OpenRouter/HTTP-запросы: настоящий ключ не нужен, квота не расходуется.

## API

- `GET /api/health` — состояние приложения, без проверки ключа и обращения к OpenRouter.
- `POST /api/ask` — JSON `{"question": "Ваш вопрос"}`.
- Ответ: `{"answer": "Ответ", "model": "nvidia/nemotron-3.5-lightning:free", "truncated": false}`.
- Вопрос: 1–4 000 символов после удаления пробелов по краям.
- `422` — неверный вопрос; `429` — лимит; `503` — проблема с ключом/доступом/балансом;
  `502` — ошибка провайдера; `504` — тайм-аут.

Вопросы и ответы не сохраняются приложением. Ответ выводится как текст, не HTML.
При достижении лимита генерации интерфейс предупреждает, что ответ обрезан.
Ошибки генерации внутри HTTP 200, включая ошибки с частичным текстом, не выдаются
за успешный ответ: API возвращает безопасное сообщение об ошибке без сырых данных
провайдера.

## Бесплатные модели и ограничения

Через `OPENROUTER_MODEL` можно выбрать только:

| Модель | API ID |
| --- | --- |
| Nemotron 3.5 Lightning (по умолчанию) | `nvidia/nemotron-3.5-lightning:free` |
| Gemma 4 31B | `google/gemma-4-31b-it:free` |

По [документации OpenRouter](https://openrouter.ai/docs/api-reference/limits),
проверенной 02.11.2026, без покупки кредитов доступно до **20 запросов в минуту и
50 в сутки суммарно на все бесплатные модели**, а не на каждую отдельно.
Провайдер модели может применять дополнительные ограничения.

Модели проверены по [каталогу API](https://openrouter.ai/api/v1/models): стоимость
входных и выходных токенов равна нулю. Код допускает только модели из списка с
суффиксом `:free` и передаёт `provider.max_price` с нулевой допустимой ценой входных,
выходных токенов и запроса. Платные модели, плагины и автоматическая замена модели
не подключаются. При недоступности вернётся ошибка, а не платный fallback.

Доступность зависит от региона, настроек приватности аккаунта и загрузки
провайдера; бесплатные модели могут исчезать из каталога. Для переключения укажите
в `.env` другую модель из списка и перезапустите сервер. При ошибке баланса или
лимита ключа проверьте кабинет OpenRouter: пополнение не требуется автоматически
для использования бесплатных моделей, но отрицательный баланс может блокировать
даже их.

Ошибка `429` от провайдера модели не означает, что общая квота аккаунта закончилась:
например, у Gemma может быть перегружен Google AI Studio. Интерфейс различает
ограничение провайдера и общий ответ OpenRouter, не показывая сырые диагностические
данные. Смена модели может помочь при ограничении провайдера, но не увеличит общую
суточную квоту OpenRouter.

Приложение дополнительно ограничивает все запросы суммарно до **10 в минуту на
процесс** и генерацию до 2 048 токенов. Reasoning явно отключён для обеих разрешённых
моделей, чтобы бюджет расходовался на видимый ответ. Если провайдер всё же вернёт
пустой ответ с `finish_reason: "length"`, интерфейс объяснит исчерпание бюджета и
предложит сократить вопрос или сменить модель, а не просто повторить запрос.
Автоматических повторов нет. Браузер ждёт до 60 секунд; HTTPX задаёт 45 секунд
ожидания сетевой операции.

Это локальный MVP без аутентификации. Лимит хранится в памяти, сбрасывается после
перезапуска и не общий для нескольких workers. Для публичного сайта сначала
добавьте авторизацию и общий rate limiter на прокси/в Redis, HTTPS и защиту от
злоупотребления ключом. CORS не защищает публичный API от сторонних клиентов.

Вопрос передаётся внешнему провайдеру. Не отправляйте конфиденциальные данные;
запрос проходит через OpenRouter к провайдеру модели. Правила хранения и обучения
зависят от провайдера и [настроек приватности](https://openrouter.ai/settings/privacy).
