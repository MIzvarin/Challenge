# Challenge — вопрос → ответ

Минималистичный React-интерфейс и Python-бэкенд, который отправляет вопросы в
DeepSeek через API OpenCode Go. Без регистрации в приложении, базы данных и истории
диалогов: каждый вопрос независим. Для API нужны подписка Go и личный ключ Console.

## Стек

- Python **3.15.2**, FastAPI, HTTPX.
- React **19.3.0**, TypeScript, Vite; Node.js **22.12+**, npm **11+**.
- Модель: **DeepSeek V4.1 Flash**, API ID `deepseek-v4.1-flash`, через OpenCode Go.

## API-ключ

1. Откройте <https://opencode.ai/console> → **Account → Personal API keys → Add API key**.
   Выберите workspace с активной подпиской **Go**. В настройках workspace разрешите
   **Settings → Privacy → Regions → Global**: это требуется для моделей DeepSeek.
2. Впишите ключ в **корневой `.env`**:

   ```dotenv
    OPENCODE_GO_API_KEY=ваш_ключ_OpenCode_Console
    OPENCODE_GO_MODEL=deepseek-v4.1-flash
   ```

   После клонирования создайте `.env` из шаблона: `cp .env.example .env`.
3. После изменения `.env` перезапустите бэкенд.

`.env` и `.env.*` исключены из Git; `.env.example` содержит только пустой шаблон.
Не помещайте ключ в React, `VITE_*`, URL, логи или README. Переменные окружения
процесса имеют приоритет над `.env`. Сервер читает файл относительно расположения
проекта, независимо от текущей директории.

Старые переменные `OPENROUTER_*` не читаются. Старый ключ не переносится в новый
провайдер. Вход в OpenCode через `/connect` сам по себе не заполняет `.env` приложения.

## Локальный запуск

Из корня проекта, с установленным Python 3.15.2:

```sh
python3.15 -m venv .venv
source .venv/bin/activate
python -m pip install -e './backend[dev]'
python -m uvicorn app.main:create_app --factory --reload --host 127.0.0.1 --port 8000
```

В другом терминале, из `frontend/`:

```sh
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Vite проксирует `/api` на бэкенд — браузер не
обращается к OpenCode Go напрямую. CORS с разрешением всех доменов не нужен.

## Сборка

Из `frontend/`:

```sh
npm run build
```

После сборки перезапустите бэкенд **без `--reload`**. Он отдаёт интерфейс из
`frontend/dist` по <http://127.0.0.1:8000>, а не из корня репозитория. `.env`
недоступен через HTTP. `npm run preview` предназначен только для просмотра статики:
для запросов к ИИ используйте Vite dev-сервер или собранный интерфейс на бэкенде.

## API

- `GET /api/health` — состояние приложения, без проверки ключа и обращения к OpenCode Go.
- `POST /api/ask` — JSON `{"question": "Ваш вопрос"}`.
- Ответ: `{"question": "Ваш вопрос", "date": "2026-11-03T12:30:00Z", "tokens": 142, "answer": "Ответ"}`.
- Вопрос: 1–4 000 символов после удаления пробелов по краям.
- `422` — неверный вопрос; `429` — лимит; `503` — проблема с ключом/доступом/балансом;
  `502` — ошибка провайдера; `504` — тайм-аут.

Вопросы и ответы не сохраняются приложением. Вопрос выводится мелким серым шрифтом,
далее — дата, расход токенов и ответ. Весь текст выводится как текст, не HTML.
`question` — исходный вопрос после удаления пробелов по краям; `date` — время
формирования ответа сервером в UTC (ISO 8601), в интерфейсе отображается в часовом
поясе браузера. `tokens` — фактическое `usage.total_tokens` от OpenCode Go, включая
входные и выходные токены, поэтому значение может быть больше 50. При отсутствии
статистики API возвращает ошибку, а не выдумывает число.

Окончательный ответ API имеет строгую схему с четырьмя обязательными полями и запретом
лишних полей; JSON Schema опубликована в `/openapi.json` (`components.schemas.Answer`).
Модель получает `response_format: {type: "json_schema", json_schema: {strict: true, …}}`
со схемой `{"answer": "…"}`. Вопрос, дату и расход токенов добавляет сервер: модель
не знает фактический расход и не должна тратить лимит генерации на повторение вопроса.
Полученный JSON дополнительно проверяется на сервере. Невалидный, пустой или
оборванный по лимиту ответ отклоняется с `502`, частичный текст не показывается.

В [каталоге Go](https://opencode.ai/inference/go/v1/models) на 03.11.2026 у DeepSeek
V4.1 Flash указан `structured_output: true`. В тот же день первоначальный интеграционный
запрос через Go с `json_schema`, `strict: true`, `stop`, прежним лимитом `max_tokens: 150` и
`thinking.type: disabled` вернул HTTP 200 и корректный JSON-ответ. В статистике
подтверждены `billing_source: go` и `cost: 0` для этого запроса. Один успешный тест
не гарантирует соответствие всех будущих ответов: серверная строгая валидация
всегда остаётся включённой. Код не заменяет `json_schema` на JSON mode молча.

**Stop sequence** — строка, на которой провайдер останавливает генерацию; сама
строка в результат не включается. В Chat Completions параметр называется `stop`:
`["<END_OF_ANSWER>"]`. Это дополнительный защитный маркер, а не замена JSON Schema
или лимиту токенов. Модель не просят дописывать маркер после JSON: нормальный ответ
заканчивается закрытым объектом. Использовать `}` или перевод строки как stop нельзя —
они могут оборвать корректный JSON. Если маркер всё же возникнет внутри объекта,
незавершённый JSON будет отклонён сервером.

Ошибки генерации внутри HTTP 200, включая ошибки с частичным текстом, не выдаются
за успешный ответ: API возвращает безопасное сообщение об ошибке без сырых данных
провайдера.

## OpenCode Go: подключение, тариф и ограничения

Приложение использует только `deepseek-v4.1-flash` и фиксированный адрес:

```text
https://opencode.ai/inference/go/openai/v1/chat/completions
```

Ключ передаётся только сервером по Bearer-схеме. Каждый независимый вопрос получает
новый UUID в заголовке `x-opencode-session`: это отдельный разговор из одного запроса,
а не история диалога. Клиент честно представляется как `challenge-qa/0.1`, не выдавая
себя за OpenCode или другой coding-агент.

**Область использования:** [OpenCode Go](https://opencode.ai/v2/docs/console/go)
предназначен для coding-агентов и ожидает соответствующий трафик. Наличие API не
гарантирует допустимость использования подписки произвольным сервисом «вопрос —
ответ». До эксплуатации подтвердите допустимость такого сценария у OpenCode.
Приложение не маскирует запросы для обхода этих условий.

**Оплата:** Go — подписка, а не бесплатная модель и не безлимитный API. Действуют
5-часовой, недельный и месячный лимиты. В Console отключите **Extra Usage**, если
не хотите расходовать pay-as-you-go баланс сверх подписки. Приложение не меняет
настройки оплаты аккаунта и не может гарантировать отсутствие доплат, если Extra
Usage включён. Адрес pay-as-you-go, другие модели и автоматические повторы кодом
не используются. Бесплатный вариант `deepseek-v4.1-flash-free` не подключается.

При `401` проверьте ключ, при `403` — подписку, права ключа, настройки регионов и
условия использования Go; при `402` — доступный объём подписки. `429` может означать
ограничение Go или провайдера DeepSeek: проверьте Console и повторите позже.

Приложение дополнительно ограничивает все запросы суммарно до **10 в минуту на
процесс** и генерацию до **50 токенов** (`max_tokens: 50`). Лимит включает весь
генерируемый JSON, но не входной запрос; токены не равны символам. Отправляется
нативный переключатель DeepSeek `thinking: {type: "disabled"}`, чтобы сохранить
бюджет для видимого ответа. В живом тесте шлюз принял этот параметр, а генерация
короткого ответа заняла 6 токенов. Если рассуждения всё же выполняются, они могут
израсходовать бюджет.
При `finish_reason: "length"` интерфейс объяснит исчерпание бюджета и
предложит сократить вопрос или сменить модель, а не просто повторить запрос.
Автоматических повторов нет. Браузер ждёт до 60 секунд; HTTPX задаёт 45 секунд
ожидания сетевой операции.

Это локальный MVP без аутентификации. Лимит хранится в памяти, сбрасывается после
перезапуска и не общий для нескольких workers. Для публичного сайта сначала
добавьте авторизацию и общий rate limiter на прокси/в Redis, HTTPS и защиту от
злоупотребления ключом. CORS не защищает публичный API от сторонних клиентов.

Вопрос передаётся внешнему провайдеру. Не отправляйте конфиденциальные данные;
запрос проходит через OpenCode Go к провайдеру DeepSeek. Ознакомьтесь с условиями
[приватности Go](https://opencode.ai/v2/docs/console/go#privacy) и настройками workspace.
