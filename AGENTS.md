# OpenSpec

- Конфигурация и контекст проекта: `openspec/config.yaml`.
- Спецификации: `openspec/specs/`; предложения изменений: `openspec/changes/`.
- Для планирования существенных изменений используйте `/opsx-propose`, для реализации —
  `/opsx-apply`, для завершения — `/opsx-archive`. Перед реализацией согласуйте план с пользователем.
- Артефакты пишите по-русски, сохраняя структурные заголовки OpenSpec и ключевые слова SHALL/MUST на английском.
